# Implementation Plan: Investment Committee Domain Model

**Branch**: `002-domain-model` | **Date**: 2026-08-10 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/002-domain-model/spec.md`

## Summary

Establish the minimal, provider-independent Pydantic v2 domain model for AIC under
`src/aic/domain/`: `Company`, `Evidence` (with a closed `EvidenceType` classification),
`FinancialSnapshot` (independently optional metrics, each a `Money` value where
monetary), `InvestmentThesis`, `InvestmentCase` (the aggregate research object), and
three forward-looking, shape-only contracts — `AnalysisAssessment` (role-agnostic, no
Bull/Bear label), `ValuationResult` (its `estimated_value` also a `Money`), and
`CommitteeDecision`. A shared `Money` value object (`Decimal` amount + ISO
4217-validated currency, no arithmetic) replaces repeated bare-`Decimal`-plus-currency
field pairs. Every identifier is a `UUID`, supplied explicitly by the caller — the
models never auto-generate one. The canonical serialized form is a plain dict via
Pydantic v2's `model_dump()` / `model_validate()`. No calculations, no
LLM/orchestration/cloud dependency, no I/O, no persistence.

## Technical Context

**Language/Version**: Python 3.12+ (matches the existing repository baseline from
001-repository-bootstrap)

**Primary Dependencies**: Pydantic v2 (`pydantic>=2.0`, already a runtime dependency
from 001-repository-bootstrap; this feature targets its `model_dump()`/`model_validate()`
API explicitly, not the deprecated v1 API); everything else needed (UUID handling,
string enums, precise decimal arithmetic, dates) comes from the Python standard
library — no new third-party dependency is introduced by this feature

**Storage**: N/A — domain models are in-memory data structures only, no persistence

**Testing**: pytest (existing), covering construction validity/invalidity, optional-field
handling, currency and evidence-type validation, and dict round-trip serialization for
every core model

**Target Platform**: Same as the existing repository — local developer machine, Windows
PowerShell as the primary documented/verified shell

**Project Type**: Single Python package; this feature adds a `domain` sub-package under
the existing `aic` package established in 001-repository-bootstrap

**Performance Goals**: N/A — pure in-memory validation and serialization, no
performance-sensitive or high-throughput requirement stated

**Constraints**: No network or file I/O, no environment-variable reads (FR-018); no
dependency on OpenAI, LangChain, LangGraph, AWS/boto3, or any market-data SDK (FR-018);
currency codes must validate against the real, *complete* ISO 4217 code set — not an
arbitrary subset — without adding a new dependency for it (research.md decision); every
identifier is a `UUID` type but is a required, caller-supplied value, never
auto-generated by the model (research.md decision, preserving spec FR-010 as written);
monetary fields use a shared `Money` value object rather than repeated bare-`Decimal`-
plus-currency field pairs (research.md decision); canonical serialized form is a plain
dict via Pydantic v2's `model_dump()`/`model_validate()`, not JSON text (spec
Clarification)

**Scale/Scope**: Eight core models (`Company`, `Evidence`, `FinancialSnapshot`,
`InvestmentThesis`, `InvestmentCase`, `AnalysisAssessment`, `ValuationResult`,
`CommitteeDecision`), one shared `Money` value object, two closed enumerations
(`EvidenceType`, `Recommendation`), and a complete internal ISO 4217 code set — this is
the complete scope, no application, agent, or persistence code

**Structure Decision**: Single-project, `src`-layout (unchanged from 001-repository-bootstrap).
This feature adds one new sub-package, `aic.domain`, with one file per entity (small,
composable models per FR-015) plus shared `enums.py`, `currency.py`, and `money.py`
modules, all re-exported from `aic/domain/__init__.py` so every model is importable from
one location (FR-019). Tests mirror that structure under `tests/unit/domain/`. No files
outside `src/aic/domain/` and `tests/unit/domain/` are touched — the pre-existing
`src/aic/agents/prompts/` scaffolding and everything from 001-repository-bootstrap are
left exactly as they are.
